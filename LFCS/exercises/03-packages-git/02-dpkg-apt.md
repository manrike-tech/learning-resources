## Exercise 1 – Install and inspect ★

1. Refresh metadata and install `tree`.
2. List the files it installed and save the list to `/root/tree-files.txt`.
3. Which package owns `/usr/bin/tree`?

<details>
<summary>Solution</summary>

```bash
apt update && apt install -y tree
dpkg -L tree > /root/tree-files.txt
dpkg -S /usr/bin/tree
```

</details>

## Exercise 2 – Find the provider of a missing command ★★

Find, without guessing, which package provides the `dig` command, install it, and confirm with `dpkg -S`.

<details>
<summary>Solution</summary>

```bash
apt install -y apt-file && apt-file update
apt-file search bin/dig
apt install -y bind9-dnsutils
dpkg -S "$(command -v dig)"
```

</details>

## Exercise 3 – Versions and sources ★

For `openssh-server`, show the installed version, the candidate version and which repository/suite each comes from.

<details>
<summary>Solution</summary>

```bash
apt-cache policy openssh-server
```

</details>

## Exercise 4 – Config files of a package ★★

1. List the configuration files shipped by `openssh-server`.
2. Edit `/etc/ssh/sshd_config` (add a comment). Detect the change with dpkg.

<details>
<summary>Solution</summary>

```bash
dpkg-query -W -f='${Conffiles}\n' openssh-server
dpkg -L openssh-server | grep ^/etc
echo "# test" >> /etc/ssh/sshd_config
dpkg --verify openssh-server     # may be silent: sshd_config is generated by postinst (not a conffile)
dpkg --verify openssh-client     # try a real conffile instead: edit /etc/ssh/ssh_config and verify
```

On Ubuntu, `/etc/ssh/sshd_config` is created by the maintainer script (ucf), not as a dpkg conffile – a good example of why you should check both `Conffiles` and `dpkg -L`.

</details>

## Exercise 5 – remove vs purge ★

1. Install `nginx`, then `apt remove` it. Run `dpkg -l nginx-common`. Do files remain in `/etc/nginx`?
2. Purge it and check again.

<details>
<summary>Solution</summary>

```bash
apt install -y nginx && apt remove -y nginx nginx-common
dpkg -l nginx-common          # rc = removed, config remains
ls /etc/nginx
apt purge -y nginx nginx-common && apt autoremove -y
ls /etc/nginx                 # gone
```

</details>

## Exercise 6 – Hold a package ★★

Hold `openssh-server`; show that `apt upgrade` keeps it back (simulate with `-s`); then unhold.

<details>
<summary>Solution</summary>

```bash
apt-mark hold openssh-server
apt-mark showhold
apt -s upgrade | grep -i "kept back" -A2
apt-mark unhold openssh-server
```

</details>

## Exercise 7 – Add a third-party repository ★★★

Add the official **nginx.org** repository for your Ubuntu release using a dedicated keyring and a deb822 `.sources` file. Show with `apt-cache policy nginx` that a version from `nginx.org` is now available. Then disable the repository without deleting the file.

<details>
<summary>Solution</summary>

```bash
apt install -y curl gnupg2 ca-certificates lsb-release
install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://nginx.org/keys/nginx_signing.key | gpg --dearmor -o /etc/apt/keyrings/nginx.gpg
cat > /etc/apt/sources.list.d/nginx.sources << EOF
Types: deb
URIs: http://nginx.org/packages/ubuntu
Suites: $(lsb_release -cs)
Components: nginx
Signed-By: /etc/apt/keyrings/nginx.gpg
EOF
apt update && apt-cache policy nginx
echo "Enabled: no" >> /etc/apt/sources.list.d/nginx.sources
apt update && apt-cache policy nginx
```

</details>

## Exercise 8 – History and logs ★

Find in the logs when `tree` was installed and by which command.

<details>
<summary>Solution</summary>

```bash
grep -B2 -A3 "tree" /var/log/apt/history.log
grep " install tree" /var/log/dpkg.log
```

</details>

## Challenge – Rebuild a server's package set ★★★

1. Save the list of manually installed packages to `/root/manual-pkgs.txt`.
2. Explain how you would reinstall exactly that set on a fresh Ubuntu server.

<details>
<summary>Solution</summary>

```bash
apt-mark showmanual > /root/manual-pkgs.txt
# on the new server:
apt update && xargs -a /root/manual-pkgs.txt apt install -y
```

(`dpkg --get-selections > sel.txt` + `dpkg --set-selections < sel.txt && apt-get dselect-upgrade` is the classic alternative.)

</details>
